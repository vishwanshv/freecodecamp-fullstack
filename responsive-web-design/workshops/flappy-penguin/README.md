## Technical Highlights

- Built a complete penguin illustration using HTML and CSS without external image assets for the character.
- Used CSS custom properties for reusable penguin colors.
- Used `position: absolute` and `position: relative` to precisely layer and position the penguin's body parts.
- Used `border-radius` and gradients to create the head, face, body, eyes, beak, arms, and feet.
- Used `::before` to create an additional body detail without adding extra HTML.
- Used `transform: rotate()`, `scale()`, and `skew()` to shape and position different elements.
- Used `z-index` to control the stacking order of the mountains, penguin, arms, feet, and ground.
- Used `@keyframes` animation to create a continuous waving motion for the penguin's arm.
- Used `transition` and `:active` to create an interactive scaling effect when the penguin is pressed.
- Used `calc()` and viewport units such as `vh` and `vw` for sizing the background and ground.
- Used linear gradients to create the sky, mountains, penguin body, arms, and ground.
