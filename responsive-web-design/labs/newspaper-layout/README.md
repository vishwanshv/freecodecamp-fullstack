## Technical Highlights

- Used semantic HTML elements such as `main`, `header`, `article`, and `figure` to structure the newspaper.
- Used CSS Grid to create the overall newspaper layout.
- Used `grid-template-areas` to assign specific sections to positions within the grid.
- Used `grid-template-columns` and `grid-template-rows` to control the proportions of the layout.
- Used `1fr` and `auto` units to distribute available space between grid rows and columns.
- Used `grid-area` to connect each HTML section with its corresponding grid area.
- Used Flexbox to center and align the cover image within its grid area.
- Used `overflow: hidden` to prevent content from extending outside its assigned sections.
- Used `box-sizing: border-box` for predictable sizing of elements.
- Used fixed typography, spacing, backgrounds, and borders to create a compact newspaper-style appearance.
