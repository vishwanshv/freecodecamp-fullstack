# Personal Portfolio – Responsive Project Showcase and Contact Page

[Live Demo](https://vishwanshv.github.io/freecodecamp-fullstack/responsive-web-design/labs/personal-portfolio/)

## Technical Highlights

- Used semantic HTML elements such as `nav`, `section`, `footer`, and anchor elements to structure the portfolio.
- Used a fixed navigation bar with anchor links for smooth navigation between sections.
- Used CSS Grid to create the responsive project gallery.
- Used Flexbox to align the welcome section, contact links, navigation items, and footer content.
- Used `100vh` to create a full-screen welcome section.
- Used CSS hover effects to reveal project title symbols and provide interactive feedback on links and buttons.
- Used `transition` and `transform: translateY()` to animate the contact links on hover.
- Used CSS Grid `grid-template-columns` and `gap` to control the project card layout.
- Used media queries to switch the project grid from two columns to a single column and adapt typography, navigation, contact links, and footer layout for smaller screens.
- Used `scroll-behavior: smooth` to provide smooth scrolling when navigating through the page.
- Used `object-fit: cover` and responsive image sizing for project thumbnails.
