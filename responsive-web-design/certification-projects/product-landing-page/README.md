# Product Landing Page

[Live Demo](https://vishwanshv.github.io/freecodecamp-fullstack/responsive-web-design/certification-projects/product-landing-page/)

A responsive product landing page for **Original Trombones**, built as part of the freeCodeCamp Responsive Web Design certification.

## Features

- Fixed navigation bar that remains at the top of the viewport
- Original Trombones logo and branding
- Navigation links to different sections of the page
- Email subscription form with HTML5 email validation
- Embedded product video
- Product features section
- Pricing cards for different trombone models
- Responsive layout using CSS Flexbox
- Mobile-friendly design using a CSS media query
- Footer with additional navigation links
