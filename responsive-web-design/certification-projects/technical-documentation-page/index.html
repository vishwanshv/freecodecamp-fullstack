Introduction to CSS

CSS stands for Cascading Style Sheets. It is a language used to control the visual appearance and presentation of HTML documents. While HTML provides the structure and content of a webpage, CSS is responsible for determining how that content looks.

Using CSS, developers can control colors, fonts, spacing, borders, backgrounds, positioning, and the overall layout of a webpage. CSS makes it possible to separate the presentation of a website from its underlying structure.

For example, HTML can create a heading, paragraph, button, or image. CSS can then determine the color of the heading, the size of the text, the spacing around the button, and where the image appears on the page.

CSS is used by nearly every modern website. It allows developers to create layouts that work across different screen sizes, including desktop computers, tablets, and mobile phones.

h1 { color: blue; }

The example above selects all h1 elements and changes their text color to blue. A CSS rule usually consists of a selector followed by one or more declarations.

p { font-size: 18px; color: #333; }

CSS can be added to a webpage in several ways. Developers can use inline styles, internal style elements, or external CSS files. External stylesheets are commonly used because they allow multiple webpages to share the same styles.

  • HTML provides the structure of a webpage.
  • CSS controls the appearance and presentation.
  • CSS can control colors, fonts, spacing, and layouts.
  • External stylesheets help keep code organized.
CSS Syntax

A CSS rule is made up of a selector and a declaration block. The selector identifies which HTML elements should receive the styles.

The declaration block is surrounded by curly braces. Inside the braces, each declaration contains a property and a value separated by a colon.

p { color: green; }

In this example, p is the selector. The color property determines the text color, and green is the value assigned to that property.

Multiple declarations can be placed inside the same declaration block. Each declaration should normally end with a semicolon so that additional properties can be added easily.

h2 { color: purple; font-size: 30px; margin-bottom: 10px; }

CSS properties describe different visual characteristics of an element. For example, the width property controls an element's width, while the background-color property controls the color behind its content.

Proper CSS syntax is important because browsers must be able to understand each rule. Missing braces, colons, or other characters can cause styles to fail or produce unexpected results.

  • A selector chooses the element to style.
  • A property defines what should be changed.
  • A value determines how the property should be applied.
  • Declarations are placed inside curly braces.
Selectors

CSS selectors are patterns used to select HTML elements before applying styles to them. Different selectors allow developers to target elements in different ways.

An element selector targets HTML elements by their tag name. For example, using p as a selector will target every paragraph element on the page.

p { color: black; }

Class selectors target elements that have a particular class attribute. A class selector begins with a period followed by the class name.

.button { background-color: blue; }

ID selectors target an element using its id attribute. An ID selector begins with a hash symbol followed by the ID value.

#header { padding: 20px; }

Attribute selectors allow you to target elements based on the presence or value of an attribute. They are useful when you want to select elements with specific attributes or attribute values.

input[type="text"] { border: 1px solid gray; }

CSS also provides more advanced selectors, including descendant selectors, child selectors, pseudo-classes, and pseudo-elements. These allow developers to target elements based on their relationship to other elements or their current state.

  • Element selectors target HTML tags.
  • Class selectors begin with a period.
  • ID selectors begin with a hash symbol.
  • Attribute selectors target specific attributes.
  • More advanced selectors can target relationships and states.
The Box Model

Every HTML element displayed on a webpage can be thought of as a rectangular box. CSS uses the box model to determine how elements take up space and interact with other elements.

The CSS box model consists of four main areas: content, padding, border, and margin. Understanding these areas is important when creating layouts and controlling spacing.

The content area contains the actual text, images, or other information inside an element. The width and height properties usually control the size of this area.

div { width: 300px; height: 150px; }

Padding creates space between an element's content and its border. Increasing padding makes the inside of an element appear larger without changing the size of the actual content.

div { padding: 20px; }

A border surrounds the padding and content areas. Borders can have different widths, colors, and styles.

div { border: 2px solid black; }

Margin creates space outside an element. Margins are used to separate elements from one another and control the distance between different parts of a webpage.

The box-sizing property can change how width and height calculations work. Using border-box makes the declared width and height include an element's padding and border.

* { box-sizing: border-box; }
  • Content contains the actual information.
  • Padding creates space inside an element.
  • Border surrounds the content and padding.
  • Margin creates space outside an element.
  • The box model affects an element's total size.
CSS Positioning

CSS positioning controls how elements are placed on a webpage. The position property can be used together with properties such as top, right, bottom, and left to control an element's location.

The default position value for most elements is static. Static elements follow the normal flow of the document and are placed according to the order in which they appear in the HTML.

.box { position: static; }

Relative positioning keeps an element in the normal document flow while allowing it to be moved relative to its original position.

.box { position: relative; top: 20px; left: 10px; }

Absolute positioning removes an element from the normal document flow. The element can then be positioned relative to its nearest positioned ancestor.

.box { position: absolute; top: 0; right: 0; }

Fixed positioning places an element relative to the browser viewport. A fixed element remains in the same location even when the user scrolls the page.

nav { position: fixed; top: 0; left: 0; }

Sticky positioning behaves similarly to relative positioning until a specified scroll position is reached. After that point, the element can behave similarly to a fixed element within its containing area.

Understanding the different position values is important for creating navigation bars, overlays, tooltips, custom layouts, and many other user interface designs.

  • Static positioning follows the normal document flow.
  • Relative positioning moves an element from its normal position.
  • Absolute positioning uses a positioned ancestor as a reference.
  • Fixed positioning attaches an element to the viewport.
  • Sticky positioning responds to the user's scroll position.
